Errors

In Blam, there's a couple types of errors, runtime errors and compiler errors. Compiler errors are raised by the compiler during compilation and runtime errors are raised during execution of code. Runtime errors can explicitly be raised during execution and can be caught within a try, catch block. 

raiseError() {
    raise Error("This is an error message")
}

main() {
    try {
        raiseError()
    }
    catch Error {
        // handle Error
    }
    catch OtherError {
        // handle other error types with multiple catch blocks
    }
}
